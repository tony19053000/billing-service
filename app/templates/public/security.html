Trust & Integrity

Security Architecture & Data Safeguards

Tallyo is engineered to the highest standard of financial safety, data integrity, and operational resilience.

Zero Raw Card Storage

Tallyo never handles, stores, or transmits raw credit card numbers or security CVV codes. Card information is tokenized via display-only representations (brand and last four digits) to eliminate PCI scope for our customers while maintaining strict audit traceability.

Authentication & Password Cryptography

All user passwords are encrypted using adaptive bcrypt hashing with individual cryptographic salts. Session tokens are generated using cryptographically secure pseudorandom number generators and transmitted exclusively over TLS 1.3 with HttpOnly, SameSite=Lax security attributes.

Workspace Isolation & Tenant Partitioning

Every API operation strictly checks tenant boundaries. Database queries mandate explicit workspace identifiers, ensuring that no member can inspect or modify subscriptions, invoices, or ledger data belonging to another workspace.

Vulnerability Disclosure Program

We welcome responsible disclosure from security researchers. If you identify a potential security vulnerability in any Tallyo service, please report it to our security team at security@tallyo.io. We acknowledge reports within 24 hours and do not pursue legal action against researchers acting in good faith.
